API
===

The highlevel python API function is :py:func:`nwaylib.nway_match`.

For an example which follows the documentation example, 
see the `nway-apitest.py <https://github.com/JohannesBuchner/nway/blob/master/nway-apitest.py>`_.

For an example computing custom priors from catalogue properties with
prior_callback, see the `nway-multiprior.py <https://github.com/JohannesBuchner/nway/blob/master/nway-multiprior.py>`_.
